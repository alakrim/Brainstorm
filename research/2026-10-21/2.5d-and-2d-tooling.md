# Raw research: 2.5D and 2D sprite tooling (2026-10-21)

> Raw report from a research agent, kept for traceability. Curated, decision-ready guidance lives in `workflows/`. Items marked **(unverified)** were not confirmed against a primary source at research time. See `reference/licenses.md` for the follow-up license verification.

## 0. Bottom line

- **Cheapest reliable 2.5D lighting path:** generated flat-lit sprite → background cutout (self-hosted rembg or BiRefNet) → Laigter (GPL-3.0, free, CPU) for normal maps. Optional Depth Anything 3 Small/Base for a height pass. Compute is near zero except DA3 at roughly $0.001–0.002 per image.
- **Cheapest 3D-to-8-direction path:** image-to-3D with TRELLIS (MIT, GLB out, 16GB+ VRAM) or TRELLIS.2 (MIT, 4B params, 24GB+) → headless Blender on CPU or cheap GPU → free-tex-packer or TexturePacker. Estimated $0.01–0.40 per character depending on whether 3D generation is self-hosted or bought.
- **Licenses to avoid for shipped commercial work unless cleared:** RMBG-2.0 (non-commercial weights), Depth Anything V3 Giant/Large and Depth Anything V2 Base/Large/Giant (CC BY-NC 4.0), Animated Drawings (archived, humanoid-only).
- **Licenses needing a legal read:** SAM 3 (custom SAM License), Marigold (RAIL++-M model license), Hunyuan3D (Tencent community license), LayerDiffuse.
- **Pixel-art cleanup is free and CPU-bound:** PixelOE (Apache-2.0) and unfake.js (MIT). Do not use AI upscalers on pixel art; use integer nearest-neighbour scaling.

| Laigter (azagaya/laigter) | Sprite normal/specular/occlusion/parallax maps | GPL-3.0 (tool; outputs are yours) | Old releases | `--no-gui` batch mode: `-d` diffuse, `-n` normal, `-c` specular, `-o` occlusion, `-p` parallax, `-r` preset. Godot asset-library plugin (asset 3422). Not a learned model |
| SpriteIlluminator | Sprite lighting | Commercial | — | TexturePacker bundle (~$69.99) |

**Godot 4 (docs 4.7):** use `CanvasTexture` (diffuse_texture, normal_texture, specular_texture; specular_shininess > 1.0). Normal maps only show when a Light2D reaches it. PointLight2D height defaults near zero, which hides normal lighting — raise height. Green-channel convention vs Laigter/DSINE: test one sprite first.

**Unity 6 (URP 2D Renderer):** add normal map as Sprite Editor **Secondary Texture** named `_NormalMap` (`_MaskTex` for masks). Material must be Sprite-Lit-Default. Enable Light2D Normal Map Quality.

Pipeline: flat-lit sprite with fixed light direction in prompt → cutout → Laigter `--no-gui` batch (or DA3 depth → height → normals for painted art) → engine. ~$0–0.002/sprite beyond generation.

## 3. Isometric / 3/4-view tiles

- Same fixed-camera prompt block + same reference image for every tile.
- **PixelLab** (hosted): REST API + MCP server, 4/8 directions, isometric tiles, tilesets. Plans ~$10–50/mo (sources conflict) **(unverified)**.
- Snapping: PixelOE (`--target_size`, `--patch_size`) or unfake.js (`snapGrid`, `maxColors`).
- Godot 4: `TileMapLayer` (TileMap deprecated). Isometric shape/layout set on the TileSet resource.
- Unity: Tilemap with Isometric grid layout.
- One orthographic camera rig; measure tile footprint once.

## 4. Pre-rendered 3D → 2D sprites (Dead Cells-style)

| Model | License | Output | Hardware | Hosted price |
|---|---|---|---|---|
| TRELLIS | MIT (some submodules separate) | GLB, PLY | 16GB+ | Self-host |
| TRELLIS.2 | MIT | GLB (4096 tex) | 24GB+ | Self-host |
| Hunyuan3D 2.1 | Tencent community license | GLB, OBJ | ~16GB shape+texture | fal Hunyuan3D v2: $0.16 untextured, $0.48 textured |
| Tripo v3.1 (hosted) | Commercial | FBX (quad), PBR | — | 20 credits (no tex), 30 (standard), 40 (detailed) |
| Meshy (hosted) | Free plan outputs CC BY 4.0; paid = owned | GLB, FBX | — | Credit price **(unverified)** |

Headless Blender: `blender -b scene.blend -P render_8dir.py -- <args>`.
Starting points: Foozle's 4/8-direction script (itch.io), oddmode-studio/BlenderSpriteSheetImporter (Godot import plugin + Blender scene), AUTeddy 8 Directions (paid), Sprite Render Kit (paid, old).
Dead Cells pipeline: 2018 talk summarized by 80.lv; public reference implementation Broxxar/PixelArtPipeline (Unity, Unlicense).
Cost estimate: 8 dirs × 8 frames × ~3s ≈ 3 min CPU ≈ $0.01 on Modal CPU.

Pipeline: neutral-pose reference image → TRELLIS/TRELLIS.2 or Tripo → clean in Blender, fixed ortho camera, toon material → render 8 dirs × N frames headless, outline in compositor → PixelOE snap, palette-reduce → pack → Godot AnimatedSprite2D/SpriteFrames, Unity Sprite Atlas + Animator.

## 7. 2D sprites

Background removal:

| Model | Code | Weights | Notes |
|---|---|---|---|
| rembg | MIT | Per model (BRIA weights commercial-restricted) | `rembg p in out` batch; models u2net, isnet-general-use, birefnet-general, bria-rmbg |
| BiRefNet | MIT | Check | ~3.5GB VRAM FP16 at 1024; variants general/lite/HR/matting |
| RMBG-2.0 | — | **CC BY-NC 4.0** | Avoid for commercial without a BRIA license |
| BEN2 | MIT | Base open; full commercial | Images and video |

Prices: Replicate 851-labs/background-remover ~$0.0005/image; rembg on Modal T4 ~$0.0005/image.

Pixel art:

| Tool | License | Notes |
|---|---|---|
| PixelOE | Apache-2.0 | `pixeloe.pixelize in --target_size 256 --patch_size 8`; modes center/contrast/k-centroid |
| unfake.js | MIT | Grid detection, snap, palette reduce; browser + Rust CLI (unfake-core); also a PyPI `unfake` |
| Pixelorama | MIT | Pixel editor (Godot-based); spritesheet export |
| Retro Diffusion | Commercial (Aseprite extension) | $20–65 one-time |

Animation frames: (A) edit-model pose frames with references, then snap all with identical settings; (B) image-to-video → ffmpeg frames → snap; (C) 2D skeletal rig (most consistent).

Packing: TexturePacker ($49.99 perpetual; indie discount); free-tex-packer **(unverified)**. Godot and Unity both import atlases directly.

Upscaling: Real-ESRGAN (BSD-3) for painted art only; never on pixel art.
